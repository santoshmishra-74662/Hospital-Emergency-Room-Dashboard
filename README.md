# Hospital-Emergency-Room-Dashboard
This project focuses on analyzing Hospital Emergency Room (ER) data using Excel, Pivot Tables, and DAX formulas to generate key insights into patient flow, wait times, satisfaction levels, and department referrals. The dashboard is designed to improve hospital performance evaluation and enhance decision-making through data-driven analysis.

Key Components of the Dashboard:
📌 Total Patient Count & Daily Trends
The dashboard tracks the number of patients visiting the ER daily. By using an area sparkline, it highlights busy days, seasonal trends, and peak hours, allowing hospital administrators to optimize staff allocation and resource management.

📌 Average Wait Time Analysis
A crucial metric in hospital management is how long patients wait before seeing a medical professional. The dashboard provides a clear visualization of wait time trends, helping identify delays and improve patient experience.

📌 Patient Satisfaction Score
The system measures average satisfaction scores to assess service quality. It uses an area sparkline to track fluctuations in patient feedback, making it easier to detect patterns and correlate lower scores with specific challenges, such as high patient volume.

📌 Admission Status Breakdown
The dashboard categorizes patients based on admission status, displaying the percentage of patients admitted versus not admitted. This helps in understanding hospital occupancy rates and improving resource allocation.

📌 Age Group Distribution
Patients are segmented into different age categories to analyze which groups visit the ER more frequently. This information assists in predicting healthcare demands for different demographics.

📌 Timeliness Analysis
To assess hospital efficiency, the dashboard calculates the percentage of patients attended within 30 minutes, providing insights into responsiveness and operational performance.

📌 Gender-Based Analysis
The dashboard includes a gender-wise breakdown, showing the proportion of male and female patients, which helps in demographic analysis and targeted healthcare strategies.

📌 Department Referral Trends
The dashboard tracks which hospital departments patients are most frequently referred to, such as General Practice, Orthopedics, and Cardiology. This data helps in understanding patient needs and optimizing department resources.

This project enhances data visualization, analysis, and hospital decision-making, making patient care management more efficient and streamlined.
